------------------------------------------------------------------------
HOW TO RUN:
------------------------------------------------------------------------
Option A (Recommended):
Double-click "Launch_Website.bat". It starts the local server and opens
http://localhost:3000 automatically in your default browser.

Option B (Direct Offline Access):
Double-click "index.html" directly in Windows Explorer. It runs cleanly
in Chrome, Edge, or Brave with zero terminal commands needed.

Option C (Command Line):
Open Command Prompt in this folder and run:
   node serve.js
Then navigate to http://localhost:3000.
